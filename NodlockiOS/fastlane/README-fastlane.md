# Fastlane for Nodlock (iOS)

Drives App Store Connect metadata, review notes and build uploads from the CLI.

- App: **Nodlock** (bundle id + team from `NodlockiOS/.env`)
- Scheme `Nodlock`, project `Nodlock.xcodeproj` (generated by `./gen.sh`, do not edit by hand)
- fastlane 2.238 via Homebrew. No `Gemfile`, no `bundle exec`.

## One-time setup

### 1. Create the App Store Connect API key

Sign in to App Store Connect as Account Holder or Admin.

1. **Users and Access → Integrations → App Store Connect API → Team Keys**
2. Click **+**, name it `nodlock-fastlane`, set access **App Manager**.
   App Manager can edit metadata, upload builds and submit for review. That covers every lane here.
3. **Generate**, then **Download** the `.p8`. Apple gives you exactly one download.
4. Copy the **Key ID** from the row and the **Issuer ID** from the top of the page.

### 2. Park the .p8 outside the repo

```sh
mkdir -p ~/.config/op-guard/asc
mv ~/Downloads/AuthKey_ABC123DEFG.p8 ~/.config/op-guard/asc/
chmod 600 ~/.config/op-guard/asc/AuthKey_ABC123DEFG.p8
```

The `.p8` is a private key. It never goes in git.

### 3. Write the env file

`~/.config/op-guard/asc.env`:

```sh
export ASC_KEY_ID="ABC123DEFG"
export ASC_ISSUER_ID="12ab34cd-56ef-78ab-90cd-1234ef567890"
export ASC_KEY_PATH="$HOME/.config/op-guard/asc/AuthKey_ABC123DEFG.p8"
```

```sh
chmod 600 ~/.config/op-guard/asc.env
```

Source it in every shell that runs a lane:

```sh
source ~/.config/op-guard/asc.env
```

Any lane that talks to Apple stops with a clear error if one of the three is missing.

## Commands

Everything runs from `NodlockiOS/`.

### Check the metadata offline

```sh
cd NodlockiOS && ./gen.sh && fastlane precheck_local
```

No network, no credentials. Confirms every metadata file exists and fits Apple's character limits, then prints the table. Run this before anything else.

### Push metadata and screenshots (no binary)

```sh
source ~/.config/op-guard/asc.env
cd NodlockiOS && fastlane metadata
```

Uploads `fastlane/metadata/` and `fastlane/screenshots/` to the App Store Connect app record. Does not submit for review.

### Build and ship to TestFlight

```sh
source ~/.config/op-guard/asc.env
cd NodlockiOS && ./gen.sh && fastlane beta
```

Builds with gym, uploads with pilot, waits for processing. Internal testers only (`distribute_external: false`).

### Build and submit for App Store review

```sh
source ~/.config/op-guard/asc.env
cd NodlockiOS && ./gen.sh && fastlane release
```

Builds, uploads the binary, uploads metadata and screenshots, and submits for review. `automatic_release` is off: after approval you press **Release** yourself.

Submission answers baked in: no IDFA, no non-exempt encryption.

## Screenshots

Drop them into `fastlane/screenshots/en-US/`. Filenames sort alphabetically, and that order becomes the display order in App Store Connect, so prefix them:

```
fastlane/screenshots/en-US/
  1_APP_IPHONE_67_pairing.png
  2_APP_IPHONE_67_prompt.png
  ...
```

deliver infers the device from the image dimensions. See `appstore/SCREENSHOT_PLAN.md` for the shot list.

`precheck_local` warns (does not fail) while the folder is empty.

## Where the copy comes from

| App Store Connect field | File |
| --- | --- |
| Name | `metadata/en-US/name.txt` |
| Subtitle | `metadata/en-US/subtitle.txt` |
| Promotional text | `metadata/en-US/promotional_text.txt` |
| Description | `metadata/en-US/description.txt` |
| Keywords | `metadata/en-US/keywords.txt` |
| What's New | `metadata/en-US/release_notes.txt` |
| Support URL | `metadata/en-US/support_url.txt` |
| Marketing URL | `metadata/en-US/marketing_url.txt` |
| Privacy Policy URL | `metadata/en-US/privacy_url.txt` |
| Primary / secondary category | `metadata/primary_category.txt`, `metadata/secondary_category.txt` |
| Copyright | `metadata/copyright.txt` |
| Notes for Review | `metadata/review_information/notes.txt` |
| Review contact | `metadata/review_information/{first_name,last_name,email_address,phone_number}.txt` |
| Demo account | `metadata/review_information/{demo_user,demo_password}.txt` (both empty: no sign-in) |

Master copy lives in `appstore/LISTING.md` and `appstore/REVIEW_NOTES.md`. Edit there first, then mirror into `metadata/`.

## Still to fill in

- `metadata/review_information/email_address.txt` and `phone_number.txt` are placeholders. Apple contacts this person during review.
- `Appfile` reads `APPLE_ID` and `ITC_TEAM_ID` from the environment. The API-key lanes do not need either.
- The app record must already exist in App Store Connect before `fastlane metadata` runs. Create it once in the web UI, or with `fastlane produce`.

## Things that break a run

- `nodlock.app/privacy` returning 404. Apple checks it.
- Version mismatch: `project.yml` sets `MARKETING_VERSION 1.0` / `CURRENT_PROJECT_VERSION 1`. Bump both there, then re-run `./gen.sh`. Never edit the generated `.xcodeproj`.
- `run_precheck_before_submit` is off on purpose: fastlane's own `precheck` needs an Apple ID login, which defeats API-key auth. `precheck_local` covers the character limits instead.
